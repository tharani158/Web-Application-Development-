# Software Requirements Specification

## Project Overview
A modern online appointment booking system that supports customers, service providers, and administrators. The application enables secure registration, booking workflows, and analytics.

## Functional Requirements
- User registration and login
- Role-based access for customers, providers, and admins
- Search and view providers
- Book, reschedule, cancel, and view appointments
- Provider schedule management
- Admin user/provider management and reporting

## Non-Functional Requirements
- Responsive web design using Bootstrap 5
- JWT-based authentication
- RESTful API architecture
- Secure password hashing with bcrypt
- Error handling middleware and validation
- MongoDB persistence with Mongoose ODM
